Jak nahrát aplikaci na GitHub Pages

Co je potřeba?

Tento jediný soubor (calculator.html) stačí přejmenovat na index.html a nahrát do Vašeho GitHub repozitáře.
  1. Přihlaste se na GitHub.com a vytvořte nový veřejný repozitář (např. modern-calculator).
  2. Uložte tento kód do souboru s názvem index.html.
  3. Nahrajte soubor index.html do hlavního adresáře (root) vašeho repozitáře (přes webové rozhraní kliknutím na Add file > Upload files, nebo přes terminál).
  4. V horním menu vašeho repozitáře klikněte na záložku Settings (Nastavení).
  5. V levém bočním menu vyberte sekci Pages.
  6. V části Build and deployment pod sekcí Branch vyberte větev main (případně master) a složku / (root). Klikněte na Save.
  7. Po chvíli obnovte stránku a GitHub vám nahoře zobrazí živou URL adresu, na které vaše kalkulačka běží!
